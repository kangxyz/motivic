# Separated finite-type étale Nisnevich sites

For `S : Scheme.{u}`, `Scheme.EtaleSeparatedFiniteType S` is the
`MorphismProperty.Over` selection of étale, separated and quasi-compact
structure maps, with all scheme maps over `S` as morphisms. Étaleness supplies
local finite presentation, so quasi-compactness gives finite type.
These objects need not be finite. Their topology is generated by actual
Nisnevich lifting families; it differs from the étale topology and from the
category `Scheme.FiniteEtale`.

Base change uses the original fiber products. The sheaf inverse/direct-image
adjunction retains its actual unit and counit. Abelian sheaf coefficients are
in universe `u + 1`; point/field comparison, injective and derived-functor
conditions remain on each interface. HI coefficient specialization stays host.
