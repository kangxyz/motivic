# Coordinate rings and units of the algebraic simplex

For a commutative `R : Type u` and `n : ℕ`,
`AlgebraicSimplex.CoordinateRing R n` is the actual quotient of
`MvPolynomial (Fin (n + 1)) R` by the ideal generated by the sum of the
coordinates minus one. `lift` evaluates coordinates whose sum is one;
`pullback` sums coordinates over the fibers of the original finite-ordinal map.
These maps form `simplicialRing R`. `mapCoefficients` uses arbitrary ring
homomorphisms, retaining independent coefficient universes and commuting with
these same pullbacks.

`Polynomial` identifies this quotient with `MvPolynomial (Fin n) R` using its
actual coordinate maps. `Units` additionally assumes `[IsReduced R]` and
identifies its units with `Rˣ`. No scheme is defined in these three leaves.
The [scheme realizations](../../AlgebraicGeometry/Simplex/AffineBoundaryOneComplex.lean)
extend the same native `AlgebraicSimplex` namespace in their geometric owner.
